# An Age Calculator App
This project is a web application designed to calculate a person's exact age in years, and months based on a provided birthdate. It is built using HTML, CSS, and JavaScript, and npm packages like [luxon](https://www.npmjs.com/package/luxon) and [JavaScript Datepicker](https://www.npmjs.com/package/js-datepicker).
